Months: 2026-06 · 2026-05 · 2026-04
2026-06-18 — Han Map: label rendering fixes (overlap + Khitan blank)
  • Map labels no longer overlap when a reading is tall (commits 753c163, 184223e, 3428e56): native-script (独自文字) lines and multi-reading labels (白讀/文讀, 文白異讀) stack extra rows, so those labels were taller than their neighbours and bled over them. Capped the native-script line height, compacted the stacked variant rows, and — the real fix — made the label de-overlap engine (grid → greedy → simulated annealing → pull-home) reserve each label's real height instead of one uniform value. A plain single-reading label is unchanged; only tall labels now claim the space they occupy.
  • Khitan (zkt) glyphs had a long blank above and below the character (commits 4a7b9e5, a2989e7): the Noto Serif Khitan Small Script font ships with hugely inflated vertical metrics (a 4.0em line box vs the normal 1.0em). Added an ascent/descent-override on the @font-face to restore sane line metrics, and switched Khitan to horizontal rendering (like Tangut) so the vertical glyph-advance blank is gone too.
2026-06-18 — Han Map: filter now localized in all 19 UI languages
  • The family × era filter fell back to Japanese for 15 UI languages (commit cb12aa0): the Han Map's own filter dictionary only had en/ja/ko/zh and defaulted the rest to Japanese, so selecting e.g. Vietnamese left the whole filter panel in Japanese. Added full translations (family names + panel strings) for the remaining 15 — vi, th, id, hi, de, fr, it, es, pt, ru, uk, ar, he, sw — reusing the codebase's existing family-name translations for consistency. All 19 supported UI languages now render the filter natively.
2026-06-18 — Han Map: review rallies #69–#75 + deterministic data guards
  • Seven multi-reviewer rallies across all 102 varieties (commits defe477, 93d442a, 3341b5a, 9f134b0, 6af52b4, 32a9119, b2fe8c8): #69/#70 all-directions passes, then targeted angles — #71 novel sense/reconstruction, #72 Han Map ↔ Word Map cross-map drift, #73 segmental (rime/medial/phonotactic), #74 reconstruction layers, #75 fresh-eyes single-cell outliers. Hundreds of cell corrections; e.g. tone-category single-character swaps (zh_kf 頭 24→42), zh_phagspa 九 g→k against its own glyph, zh_db 鳥 niɔ→niau.
  • New deterministic guard suite (commits fde883c, ab1f83a, 560f2f5, c018be8, 76f9ab5, 9b81ffd, d7ff09a, 0b1e066): rather than re-running LLM rallies forever, systematic error classes are now exhausted by code — Middle-Chinese tone-category consistency, surface↔IPA field integrity + tone agreement + phonotactic legality, variant structural integrity, native-script block + kana↔romaji skeleton, Word Map duplicate keys, Lang Map role integrity. A one-command runner (tools/check_all.js) plus a GitHub-Actions workflow and a pre-commit hook now block any commit that reintroduces these defects.
  • Hokkien standardized to Tâi-lô (commit e0a65a8) across 8 varieties (223 surface cells, POJ → Tâi-lô); 魚 colloquial ŋ̍ regularization and cnp 三/南/心/飲 -m finals (commits a4e9df3, dcf98df); zh_jh relabelled to Nanjing.
  • With corrections from kori228 (@kori228, PR #8: wuu_sz 行 ghaon6→ghaon2). ありがとうございます！
2026-06-18 — Word Map rally: 37 corrections (18-reviewer audit)
  • IPA and wrong-word fixes across ~56 languages (commit e94fc59): orthography→IPA corrections — Arapaho ⟨c⟩=/tʃ/, Corsican ghj=/ɟ/, Manx th=/t/ with no spurious palatalization, Old Spanish ʤ→ʒ / ʦ→t͡s, Old Norse/Nynorsk rhotic ɹ→r, Dungan/Kalmyk syllabic-nasal fixes — plus six wrong-word surfaces (Brahui native Dravidian hand/eye, Fulfulde good moƴƴo, Kashmiri cat براري, Zhuang drink gwn).

2026-06-16 — Han Map: iPhone tofu fix for new jamo + Nôm glyphs
