# English (en): source language

- English is the source every translation follows, so write it to be translatable: one point per sentence, no idiom that only works in English, and no pun the fact depends on.
- Register: plain magazine prose. Use contractions sparingly. British or American spelling is fine, but be consistent within an article.
- Avoid: "not X — it is Y", "Crucially,", "The result:", "Two words. A whole sentence.", "race against time", "Rosetta Stone", "time capsule", "One X to rule them all", questions answered in the next line.
- Numbers that appear in several articles (for example Taa's consonant count) should be worded the same way everywhere.
