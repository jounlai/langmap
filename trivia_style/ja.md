# 日本語 (ja)

- **文体**：だ・である調で統一する（です・ます調の記事を混ぜない）。雑誌の読み物の調子で書く。
- **避ける表現**
  - 「〜のである」「〜なのだ」を連発しない。段落末を決め台詞で締めない。
  - 「実は」「興味深いことに」「注目すべきは」「〜と言えるでしょう」を使わない。
  - 「──」や「：」で話を溜めない。
- **翻訳調**
  - 「地図は〜する」のような擬人化を避ける。無生物主語の他動詞文（「この語はさらに東へ行った」）も避ける。
  - 名詞を連ねず（「音体系の異常な豊富さには三層ある」）、動詞で言い直す。
  - 「今あなたが読んでいるラテン文字」のように、日本の読者には事実でない呼びかけをしない。
- **表記**
  - 言語名はサイトの表記に合わせる（ベトナム語。越南語とは書かない）。
  - シナ・チベット、パクパ文字、カタカナ、ひらがなはこの表記で書く。
  - 本文中の表やラベルに英語を残さない（Mandarin (zh): → 普通話（zh）：）。
