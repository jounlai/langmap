# Русский (ru)

- Научно-популярный журнальный стиль.
- Избегать кальки с английского:
  - цепочек страдательных оборотов и отглагольных существительных
  - «интересно, что», «на самом деле» как связок
  - «это не X — это Y» ради эффекта
- Кавычки «ёлочки»; тире с пробелами, но без злоупотребления.
- Заголовки с прописной только в первом слове.
- Единое написание терминов по сайту (спорные: сандип, гууг-; см. trivia_reviews/13).
- Калька «X имеет / обладает»: писать «у X есть…» или «в X — …».
- Без барабанной дроби: «Два слова. Полное предложение.», «Почему? Потому что…» — сводить в одно утверждение.
- Без штампов: капсула времени, Розеттский камень, гонка со временем, «один знак, два мира».
- Типографика: «ёлочки», «против» вместо vs., «с 1868 года», «около», «н. э.», короткое тире в диапазонах (1447–1448), десятичная запятая, «83 %».
- В заголовках после двоеточия — строчная буква.
- Родные глаголы вместо кальки: позиционировал, триангулировать, философия дизайна.
- Писать для русского читателя: не «для английского уха», не «как мы говорим „эй-би-си“».
- Единые написания: Бакстер, Ели Жэньжун, ячейка (клетка карты), хангыль со строчной.
