## Issues found
No errors found — all cells verified correct.

Notes on cells that drew scrutiny but were confirmed correct:
- **win (Ho-Chunk) i = you = "nee"** — The identical 1sg/2sg forms are a real feature, not a copy-paste slip. 1sg "nee" is well attested (e.g. *nee wahanąk* "it's me talking"), and the 2sg reflex of Proto-Siouan \*rį́·(k)e regularly surfaces as "nee" in Winnebago (\*r → n before a nasal vowel), so the homophony is phonologically expected; person is disambiguated on the verb in this pro-drop language.
- **cro (Crow) star = "ihké"** — Confirmed against the Crow Language Consortium dictionary (ihká/ihké "star"; cf. *Ihka Sáhpua* "Seven Stars," the Big Dipper). Crow "name" = "iláshe" (i-láashe) is likewise the standard possessed noun.
- **myn (Classical Maya) i = "hiin", you = "hat"** — Matches Kaufman & Norman's reconstructed Proto-Ch'olan independent pronoun set (hiin, hat, ha').
- **one/ono (Oneida/Onondaga) name = "yukyáts"/"yaʼts"** — Verbal ("(my) name is…") rather than the nominal strategy used in onn/cay/tus, but this is the conventional citation for "name" in these polysynthetic languages and is dictionary-attested; not treated as a wrong-sense error.
