# Wordmap review #411 — round-2 rally: ten family-domain reviewers over all 1,113 languages

## Method
Ten expert-persona reviewers, one per language-family domain, each auditing all 25 word cells for every language in their domain (27,825 cells total). Each was given the same brief: report only defects they could defend to a specialist, never invent a replacement (`corrected: null` if unsourced), and — the rule that mattered most — **do not normalise dialects toward their standard language.**

Three threads died to server errors mid-run and were relaunched, one of them split in half. A dying thread left behind a single half-formed hunch (Tocharian B `cat` = `kweŋ` might be the oblique of *dog*); it was handed to the relaunched thread as a lead, and it proved correct.

## The three big ones

### Gondi (`gon`) — the row is Hindi
Sixteen of 25 cells hold Hindi words with **Hindi IPA**: `खाना` /kʰaːnaː/, `पानी` /paːni/, `घर` /ɡʰər/, `आग` /aːɡ/, `चाँद` /tʃaːnd/, `सूरज` /suːraj/, `दिल` /diːl/. The dual "Devanagari / Telugu" surface was the tell — it pairs a Hindi word with a Telugu gloss, never a Gondi word in two scripts. Only `nanna`, `parol`, `sukkum`, `rend`, `nimma` are genuinely Gondi. Deferred to review #412 for a sourced rebuild.

### Dolgan (`dlg`) — nine cells hold the wrong word
`one` held **биэр** 'to give' (the numeral is биир). `water` held **уус** 'blacksmith' (уу). `hello` held **сайын** 'summer' (дорообо). `father` held **эжэ** 'elder sister'. Also sun, drink, eat, hand, moon, tree. Every correct cell in the row matches Yakut exactly, so this is a Yakut import that went wrong at nine points.

### Jivaroan (`acu`, `jiv`) — ⟨j⟩ read as /dʒ/
Achuar and Shuar spell /h/ with ⟨j⟩. Ten cells transcribed it as /dʒ/ — `jii` 'eye' as /dʒiː/, `jea` 'house' as /dʒea/. The dataset refuted itself: its own Aguaruna (`agr`) row has the same words with the correct /h/.

## Two systematic transcription errors

**The Cushitic ⟨c⟩ trap, sharpened.** Last round found Somali ⟨c⟩ = /ʕ/ (not /tʃ/) and ⟨x⟩ = /ħ/ (not /x/); three Somali cells still had it wrong. This round also caught the *mirror* error: **Afar and Saho use the opposite convention** — ⟨c⟩ = /ħ/ and ⟨q⟩ = /ʕ/ — and seven Afar/Saho cells had been "corrected" toward the Somali values. Fixed in both directions.

**The Spanish `perro` column.** The Romance thread noticed but did not report it, judging itself insufficiently confident; a follow-up settled it with sources. Four rows (`es_cr`, `es_ni`, `es_bo`, `es_uy`) wrote the **tap** `peɾo` — which is `pero` 'but', a minimal pair. Costa Rican and Andean /r/ is *assibilated* [r̝], never a tap. Two rows (`es_gt`, `es_sv`) wrote `peːro`, and Spanish has no phonemic vowel length. Puerto Rican wrote **`pelo`** — 'hair'. Puerto Rican lateralisation applies to **coda** /r/ (*puerta* → [ˈpwelta]); the intervocalic trill is realised uvular/velar, so `peʀo`.

## A deterministic checker came out of this
Five separate reviewers independently used the same heuristic: *a cell that duplicates another cell in the same row is the fingerprint of a bad import.* That is mechanical, so it is now [`tools/intra_row_dup_check.js`](../tools/intra_row_dup_check.js). Run over all 1,113 languages it re-discovers, with no linguistic knowledge at all, `ii` dog=star, `qxs` heart=sun, `kgg` one=you, `szy` good=love, `koy` sun=star, `dsh` house=moon, `dbq` mother=one, `xhu` eye=two — and surfaces candidates nobody reported (`xav` eat=father, `ter` cat=father, `abq` dog=eye, `mev` dog=heart / drink=eye / fire=hand).

It is **informational, not a gate**, because genuine polysemy is everywhere: Fijian `vinaka` really is both 'good' and 'thanks', Hawaiian `aloha` is both 'hello' and 'love', and Toki Pona's `soweli` covers cat and dog by design.

`tools/affricate_tie_check.js` was also extended: its stop inventory lacked the retroflexes ʈ ɖ, which is how `kjb`'s `ʈ͡ʂʼ` slipped past. Reverting `words/star.js` and re-running now reproduces the catch.
