# Review 438 — ラリー2／表記スタイルと接触言語の混入（新3語）

**日付:** 2026-08-19
**対象:** `words/red.js` `words/fish.js` `words/three.js`
**手法:** ラリー1が「行の作法」を見たのに対し、本ラリーは**セル自身の書き方**を3軸で見る。
いずれも決定的判定で、LLM 判断を挟まない。

| 軸 | 問い |
|---|---|
| 語幹表記 | 先頭ハイフン等、コーパスの house style を外れた引用形になっていないか |
| 接触言語 | 系統の異なる言語に、支配言語の語形がそのまま入っていないか |
| 転写スタイル | 同一行／新3語間で ɫ↔l、ɹ↔r のような**純粋な転写選択**が割れていないか |

## 軸1：先頭ハイフンの語幹形 — 22件修正

`nym=-laluku` `bxk=-besemu` `yao=-cheejewu` `lua=-kunze` `lol/tll=-kunza`
`tum=-swesi` `seh=-funga` `ngl=-fila` `vmw=-thiru` `tem=-yim` `ewo/bum=-nyín`
`agq/mgo/dur/bom=-bàŋ` `ekp/izz/ets=-bara` `urh/iso=-wowe` — red の22セル。

バントゥ学の語幹引用法としては正しいが、**このコーパスの規約ではない**。
既存29,490セル中、先頭ハイフンは**31件しかなく、その全てが義務的所有名詞**
（Athabaskan/Algic の `name/nv=-zhiʼ`、`eye/hup=-na:ʼ`、`mother/hup=-an’` など）。
バントゥ系の既存セルは `nyekundu` `bomvu` `tsvuku` `isabi` のように接頭辞込みか裸で、
ハイフンを付けない。22件からハイフンを除去。

再構形の `pban="*-kúndù"` `psem="*ʔadam-"` 等は**据え置き**。既存の
`sun/pban="*-júbà"` と同じ再構表記であり、別規約。

`jya="kə-wu-rnɛ"` も形態素ハイフンを除去（同行の他セルは `tʃʰiʂ` `kanəs` と非分割）。

## 軸2：接触言語の混入 — 6件検出、いずれも正当

支配言語（es/en/fr/pt/sw/ar/ru/zh/hi/id/tr）の語形と完全一致し、かつ**その語族に属さない**
言語を全走査。ヒットは6件のみで、すべて誤検出または正当な借用だった:

- `la` Latin / `fax` Fala の `tres` — 語族文字列の表記ゆれによる誤検出
- `ch` Chamorro の `tres` — スペイン語数詞の**実在する借用**。同行の one=`unu`、
  two=`dos` と系列が揃っており、正しい

一方、機械では拾えないが**出典のないフォールバック**として自認するもの:
`rim` Nyaturu・`rwk` Rwa・`asu` Asu の fish=`samaki`（スワヒリ語形）。
`ksb` Shambala の samaki は ASJP に裏付けがあるが、上記3件は無い。→ **ラリー3へ送付**。

## 軸3：転写スタイルの割れ — 29件修正

同一行の既存32セルが片方の記号だけを使っている（3倍以上の偏り）のに、新セルが
他方を使っていた箇所を機械的に是正:

- **テュルク諸語20行**の fish が `bɑˈɫɯq` と軟口蓋化 ɫ を使用。既存行は `l` が優勢
  （sah 4:0、tyv 3:0、kjh 3:0、alt 3:0…）→ `l` に統一（slr cjs tr sah tyv kjh alt az
  azb gag kk tk kum nog crh xqa kaa otk ota qxq）
- **英語3行**の three が `θri`（歯茎ふるえ音 r）。英語行は `ɹ` で統一されている
  （en_us 4:0）→ `θɹiː`（en, en_us, en_ca）。`en_sco` `fo` `rmy` `tcs` も同種
- **ノルマン系3行**の three が `trɛ`。行は `ʁ` が6:0 で優勢 → `tʁɛ`（nrf, nrf_gg, fra_jer）

### 是正しなかったもの（音韻として正しい）

スペイン語系21行の「red=`ˈroxo`（ふるえ音 r）／three=`tɾes`（はじき音 ɾ）」は
**語頭 r と子音後 ɾ の対立**そのもので、スタイルの割れではない。同様にブラジル・
ポルトガル語 `veʁˈmeʎu` / `tɾes`、バスク語、カタルーニャ語も据え置き。

## 副次的知見：音素逸脱チェックは今回使えなかった

review 432 で Konso 行の Oromo 混入を暴いた「その言語に無い音素」検査を試したが、
**32語では言語の全音素が出そろわない**ため755件の偽陽性を生んだ（英語行に ɛ が
他に出てこない、スペイン語の x は rojo にしか出ない、等）。転写選択のペア
（r/ɾ/ɹ、l/ɫ、ʃ/ʂ/ɕ、x/χ）に限定して初めて信号になる。汎用の音素検査を作るなら
**語数を増やすか、meta に音素目録を持たせる**必要がある。
