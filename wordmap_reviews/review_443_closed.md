# Review 443 — 日韓ラリー3／方言行の実在性（差異率の計測）

**日付:** 2026-08-19
**対象:** 日本語方言8行・琉球3行・朝鮮語方言6行
**手法:** 「その方言らしいか」をLLMに問うと、**東京規範を地方に当てはめる誤検出**が
大量に出ることが reader report（2026-08-09）で分かっている（[[rally-dialect-false-positives]]）。
そこで判断を挟まず、**親言語および兄弟方言との一致率を機械計測**した。

## 琉球3行 — changelog が指摘した問題は解消済み

2026-08-09 の記録は「宮古と八重山が81%文字一致しており、相互理解不能な2言語として
あり得ない」としていた。現在:

| 対 | 表記一致 | IPA一致 |
|---|---|---|
| ja_oki ~ ja_mvi | 31% | 21% |
| ja_oki ~ ja_rys | 38% | 28% |
| **ja_mvi ~ ja_rys** | **55%** | **45%** |

**81% → 55% に低下**。残る一致も大半は漢字表記の共有（水・火・月・目・手・木・家・犬）で、
読みは異なる。表記・IPA が完全一致するのは13セルで、`wool=わうわう`（擬音語）を除けば
`てぃだ`(sun)・`肝`(heart) など琉球祖語からの共有語彙。**再構築の必要は無い**と判断する。

いずれの行も日本語（ja）との IPA 一致率は **0%**。

## 日本語本土方言 — 一致率は高いが「誤り」ではない

| 行 | ja との表記一致 |
|---|---|
| ja_osa 大阪 | 67% |
| ja_kyo 京都 | 70% |
| ja_hir 広島 | 69% |
| ja_hak 博多 | 70% |
| ja_aom 青森 | 64% |
| ja_kg 鹿児島 | 56% |
| ja_sd 仙台 | 54% |

大阪≡京都は30セル中26セルが表記もIPAも完全一致するが、これは**正しい**。
両者を分けるのは主にアクセント（高低）であり、**本コーパスのIPA欄はピッチアクセントを
記録していない**ため、原理的に差が出ない。

> **構造的な指摘**: 関西方言と東京方言の最大の相違点であるピッチアクセントが、
> 現在のデータモデルでは表現できない。方言行を増やすほどこの限界が目立つ。

## 実害1件：仙台行が自分の音韻規則を破っていた

`ja_sd` は**母音間有声化を行全体で明示**している — `heart=こごろ/koɡoɾo`、
`cat=ねご/neɡo`、`hello=こんぬづは`、`computer=コンピューダー`。
ところが私が入れた2セルだけがそれを外していた:

- `red = 赤い/akai` → **あがい/aɡai**
- `fish = 魚/sakana` → **さがな/saɡana**

同じ東北の `ja_aom` は既に `あがい` `さがな` としており、仙台だけ標準語形だった。是正。

## 差異率による自己点検：新3語が方言を差別化できているか

各行の「既存32語での親言語一致率（＝その行が本来どれだけ違うか）」と、
「私の3セルの一致率」を比べた。後者が前者を20ポイント以上上回る＝差別化不足。

| 行 | 既存32語の一致率 | 私の3セル | 判定 |
|---|---|---|---|
| ja_osa / ja_kyo / ja_hir | 67–70% | 100% | 正しい（語彙は共通、差はアクセント） |
| ja_edo | 67% | 100% | 正しい（赤い・魚・三は江戸期も同形） |
| **ja_sd** | **54%** | **100%→33%** | **是正済み** |
| ja_hak / ja_kg | 70 / 56% | 67% | 赤か で差別化 ✓ |
| ja_aom | 64% | 33% | あがい・さがな で差別化 ✓ |
| ko_jl / ko_jeju | 72 / 54% | 0% | 뻘겋다・싯 等で差別化 ✓ |
| ko_kp | 82% | 100% | 正しい（DPRK標準語は同語形） |
| **ko_bus** | **73%** | **100%** | **差別化不足の疑い** |
| **ko_yb** | **70%** | **100%** | **同上** |
| **ko_hg** | **65%** | **100%** | **同上** |

### 慶尚・咸鏡・延辺の3行は保留

`ko_bus` は `eat=묵어`・`father=아부지`・`hello=안녕하이소` と明確に方言化されているのに、
私の red=빨갛다 / fish=물고기 / three=셋 は標準語のまま。慶尚方言なら 뻘겋다 系が
予想されるが、**典拠を持たないので投入しない**。同じく `ko_hg`（`one=한나`・
`mother=어머이` と差別化済み）、`ko_yb`。

reader report の教訓どおり、**「標準語と同じだから間違い」ではない**。
出典を当ててから直すべき箇所として記録する。

## 方針質問（言語非依存）

**ピッチアクセント／声調を IPA 欄に入れるか。** 現状、中期朝鮮語は傍点を表記欄に
持つ（review 441）が、日本語方言はアクセントをどこにも持たない。関西・東京の
区別が地図上で消えているのはこのため。表記欄に付けるか、IPA に付けるか、
第3のフィールドを設けるかは、方言行を増やす前に決めるべき。
