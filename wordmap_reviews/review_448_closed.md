# Review 448 — orange のルート分類と部分語ポリシー（ラリー5／5）

**日付:** 2026-08-19
**対象:** 新規部分語 orange（🧪）と、汎用化したルート標識の機構

## ポリシー違反 2件 — 修正

### A. 時代錯誤のセル 2件を削除

部分語は「その概念が実在する範囲だけを塗る」地図である。甘いオレンジは16世紀、
苦いオレンジでも中世の到来であり、次の2行は**その言語が存在した時代に果物がない**:

| 行 | 削除した値 | 理由 |
|---|---|---|
| la 古典ラテン語 | arantium | *aurantium* は中世ラテン語。ローマにあった柑橘はシトロン |
| sga 古アイルランド語 | oráiste | 現代アイルランド語が英語・仏語から借りた語。600–900年には無い |

同じ理由で、変種を足す際も **el_grc・ja_heian/chu/edo/kanbun・ko_mid/gor/em・
zh_song/tang/han・vi_han・ar_qur・he_mis・de_lut は足していない**。
いっぽう **fa_clas 古典ペルシア語には نارنج を新設した** — naranj ルートそのものの
出発点であり、苦いオレンジは古典期のペルシアに実在する。

### B. 地理的パリティ — 105セル追加

[[partial-word-policy]] は「同形の方言セルを間引かない（地図は親→変種を継承しないので、
変種は自分のセルを持たないと点が出ない）」と定める。cuckoo 456セル・tea 187セルは
この方針で運用されている。orange は当初272セルで、**英語19変種・スペイン語13変種・
中国語15変種などが抜けていた**。同方針で105セル追加し **375セル**（naranj 188 /
portakal 51 / china 45 / local 91）。

## ルート標識の汎用化

tea 専用に `currentWord === 'tea'` と `.tea-cha/.tea-te/.tea-other` の CSS クラスで
書かれていた仕組みを、**語のデータ側から駆動する形**に置き換えた:

- `WORDS[id].family[code]` → ルートキー、`WORDS[id].routes[key].color` → 色（インライン）
- 凡例は `routes` を走査して実行時に組み立て（19 UI言語、行数はルート数に追随）
- CSS もマークアップも語ごとに触る必要がなくなった。tea は同じ経路に載せ替え、**表示は不変**

## ルート分類で判断を要した箇所

| 行 | 分類 | 根拠 |
|---|---|---|
| hi संतरा | **portakal** | ポルトガルではなく**シントラ**（Sintra）由来。同じ航路の命名 |
| ar_ma لتشين / arq تشينة | **china** | オランダ経由ではなくフランス語 *la Chine* から独立に。ルート名を「中国にちなむ」に改めた |
| de Orange / nds Apelsien | naranj / china | ドイツ語圏がこの2ルートの境界に載る |
| ja オレンジ・ko 오렌지・ta ஆரஞ்சு・ml ഓറഞ്ച് | naranj | 英語 orange 経由だが語源は naranj |

| pl pomarańcza・hu narancs | naranj | ラテン *pomum aurantium* 経由でも語幹は نارنج |
