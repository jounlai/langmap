# Review 450 — 汚染の全域掃討（ラリー1／5）

**日付:** 2026-08-27
**切り口:** `ddn` を捕らえた「無関係な言語とのバイト一致」を、今セッションの変更ではなく
**アトラス1,164行すべて**にかける。

## 方法

`ddn` 事件の本質は「1セルが他言語と一致したこと」ではなく **「無関係な2行が複数概念で
同時に一致したこと」** だった（blood・tongue・tooth がソンガイ3行と、night が Dendi と）。
偶然の一致は概念1つで止まる。よって:

1. 語族ラベルをストック単位に畳み込む（Niger-Congo / Bantu / Atlantic-Congo は同一など）
2. 借用が当然の概念を除外（computer, sushi, tea, orange, mother, father, poop …）
3. **異なるストックの行の組が3概念以上で同形**になる場合を列挙し、地理距離を添える

## 結果 — 汚染はゼロ

125組が該当したが、上位から順に全て説明がついた:

| 組 | 一致数 | 説明 |
|---|---|---|
| `uln` ⇄ `de`/`de_ch`/`de_at`/`de_lu`/`de_lut`/`pdc` | 13–18 | ウンザードイチュはドイツ語を語彙供給言語とするクレオール |
| `cbk` ⇄ スペイン語24変種 | 9 | チャバカノはスペイン語ベースのクレオール |
| `kea`/`pt_gw` ⇄ ポルトガル語 | 11 | 同上（ポルトガル語ベース） |
| `p_jpn` ⇄ `p_ryu` | 18 | 日琉祖語と琉球祖語 |
| `mixtec`/`mix`/`mxv`, `ote`/`otq` | 21–25 | **同一語族なのにラベルが割れていた**（下記） |

**新たな汚染は1件も見つからなかった。** `ddn` が唯一だったことになる。

## そのかわり、メタデータの構造欠陥が3件出た — 修正

掃討の副産物として、`meta.family` が**分類キーとして壊れている**ことが露出した。
この文字列は2箇所で**テキストではなくキーとして**読まれる:

- `tree.html` の `parseFamilyPath()` は `(` の前を丸ごと**トップ階層ノード名**にする
- `my-languages.js` の `familyTop()` は `[>,;(]` で切って**語族数を数える**

### A. `>` 記法の16言語が系統樹で浮いていた

`Indo-European > Italic > Latino-Faliscan`（xfa）は `(` を含まないので、文字列全体が
トップ階層になる。つまり**印欧語族の子ではなく兄弟**として、系統樹に独立した枝が生える。
同様に浮いていたのは:

`xfa` `xum` `xve` `osc`（イタリック諸語）、`pot`、`vls`、`fkv` `fit`、`hif`、`zgh`、
`aln`、`rmt`、`fia` `fvr`、`lun`、`tsj`、`lep`

房内記法（637件中557件が採用）に統一。`Indo-European (Italic, Latino-Faliscan)` の形。
**トップ階層ノードは 128 → 111 に減った。**

### B. `Oto-Manguean` と `Otomanguean` の分裂

`mixtec` `mix` `zap` `ote` が前者、`zts` `maz` `mxv` `otq` が後者。
系統樹では別語族の枝になり、`my-languages` の「語族数」も水増しされていた
（サポテコ語とマサワ語を話す人に「2語族」と表示される）。4行を `Oto-Manguean (…)` に統一。

### C. `Indo-European?` が印欧語族を分岐させていた

リブルニア語 `xli` の所属は実際に不確実だが、`?` 付きの文字列は**それ自体が別の語族キー**に
なる。不確実性を保ったまま分岐しない形に:
`Paleo-Balkan (unclassified; possibly Indo-European and Illyrian-related, possibly pre-IE)`

1. `(` の前に `>` `/` `?` を含まない（そこがキーだから）
