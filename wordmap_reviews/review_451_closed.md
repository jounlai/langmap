# Review 451 — 行内の表記規約違反（ラリー2／5）

**日付:** 2026-08-27
**切り口:** review 449 で `fro` の `◌̯` を捕らえた考え方を全域へ。
**「その行が同じものを別の書き方でも書いていないか」**を機械的に測る。

## 方法の選定 — 最初のやり方は使えなかった

まず「行の中で1セルにしか現れない発音区別符号」を列挙した。634件出たが、
**ほぼ全て正当**だった — 二重母音のある語にだけ `◌̯` が付き、音節主音の子音がある語にだけ
`◌̩` が付くのは当たり前で、hapax であること自体は誤りの証拠にならない。

`fro` が誤りだったのは hapax だからではなく、**同じ行が同じ二重母音を `kwɛr`・`pwɛˈsõn` と
`w` でも書いていた**からだ。そこで判定を「同一表記が同じ行で異なるIPAを持つ」に変えた。

## 発見 — 同一表記・異IPA が59行

`ru собака`（atsign/dog で `/sɐˈbakə/` と `/sɐˈbakɐ/`）、`pmt rima`（five/hand で `ɾ` と `r`)、
`sn`/`mxc`/`ndc` の `mvura`、`pkp lima`・`wls nima`・`pag lima`（強勢の有無）、
`bca no`・`lis nyi`・`kac wa`（声調の有無）など。

**うち大半は「どちらが正しいか」に言語ごとの判断が要る**（`br te` は茶と2人称で本当に長さが
違うかもしれない、`sux 𒌓` は同じ楔形文字の2通りの読み UD=utu と BABBAR で正当）。
そこで、**音韻判断なしに白黒がつく1クラス**に絞った。

## 修正 A — 半母音を `j` と `y` で書き分けていた 12セル / 10行

IPA では `j` が硬口蓋接近音、`y` は前舌円唇母音である。10行がこれを混用していた。
決定打は **アグアルナ語**で、同じ語 `yumi` が water では `/jumi/`、rain では `/yumi/` だった。

| | 表記 | 修正 |
|---|---|---|
| `agr` rain | yumi | /yumi/ → **/jumi/** |
| `nog` earth / wind | ер / ел | /yer/ /yel/ → **/jer/ /jel/** |
| `crk` i / you | ᓂᔭ / ᑭᔭ | /niya/ /kiya/ → **/nija/ /kija/** |
| `guc` rain | huya | → **/huja/** |
| `chb` tree | quye | → **/kʷje/** |
| `dtp` tree | kayu | → **/kaju/** |
| `tsi` earth | laxyuup | → **/laxjuup/** |
| `yrk` earth | ya | → **/ja/** |
| `kca` rain | yer̃t | → **/jer̃t/** |
| `nez` thanks | Qe'ci'yew'yew' | → **/kets͡ijewjew/** |

いずれも**同じ行が他のセルで `j` を使っている**ことを確認したうえで直した。

## 修正 B — 祖語3行の内部不整合 6セル

新設ガードが追加で見つけた。表記欄は出典どおり `y` でよいが、**IPA欄が同じ行で割れていた**:

| 行 | `j` で書いていたセル | `y` で書いていたセル → 修正 |

| `pmng` 祖モンゴル語 | *yasun /jasun/ | *koyar /koyar/ → **/kojar/** |
| `p_sit` 祖漢蔵語 | *bya /bja/ | *dzya /dzya/・*tya-n /tya-n/・*yip /yip/ → **/dzja/ /tja-n/ /jip/** |
| `p_dra` 祖ドラヴィダ語 | *yām /jaːm/ | *yān /yān/・*peyar /peyar/ → **/jaːn/ /pejar/** |

## ガード新設 — そして一度作り直した

最初の版は「母音の直前の `y`」を違反とした。**57件を誤検出した** — `fi syödä /syødæ/`、
`yue 水 /sɵy˧˥/`、`zh_song 血 /xyɛt/` の `y` は前舌円唇母音であって半母音ではない。

作り直した版は**音韻判断を一切しない**: ラテン表記に「y＋母音字」を含むセルだけを取り、
**その `y` を同じ行が `j` にも `y` にも写像していれば**違反とする。前舌円唇母音の `y` は
そもそも表記に現れないので巻き込まれず、`y` で一貫している行（祖セム語 *ʕayn-、
古ビルマ語 klyit）は通る。作り直し後の検出は6件、すべて実際の不整合だった。

`tools/glide_notation_check.js` を `check_all` に配線。

## 残した観察

同一表記・異IPA の残り約50件（`ɾ`/`r`、強勢の有無、声調の有無）は言語ごとの判断が要るため
未修正。**声調言語で片方だけ声調が欠けている**もの（`bca no`・`lis nyi`・`kac wa`・
`yiz ȵi`）は次周（452）の対象にする。
