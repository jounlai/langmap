# Review 455 — Han Map のデータ整合（全体ラリー1／10）

**日付:** 2026-08-27
**切り口:** WordMap を離れ **Han Map（120言語 × 61字）** を見る。
review 450 で WordMap 全域を掃討した「汚染」（ある行が別の行のコピー）の
同じ切り口を、まだ一度も当てていない Han Map に当てる。

## 前置き — 自分の測定ミスを1件潰した

最初に「`ja` が61字中1セルしかない」と出た。日本語がほぼ空なら異常なので追ったところ、
**probe の誤り**だった。`HAN_DATA[字].surface.ja` は存在せず、日本語の読みは
漢音/呉音の複数読みなので **`HAN_VARIANTS`** 側に入っている。正しい経路で数えると `ja` は
**61/61**。全体の充填率も 89.6% ではなく **6987/7320 = 95.5%** だった。

以後のガードは `HAN_VARIANTS` を必ず経由する。これを踏まないと `ja`・`nan`・`czh` の
ような複数読み言語が「空行」に見える。

## 発見 — 6行・366セルが隣接方言の丸ごとコピー

surface と IPA を連結したセル単位で、全120言語の総当たり一致率を取った。

| 一致 | ペア | 名称 |
|---|---|---|
| **61/61 (100%)** | `hsn_hy` == `hsn` | 衡陽湘語 == 長沙湘語 |
| **61/61 (100%)** | `cnp_gl` == `cnp` | 桂北平話(桂林) == 南寧平話 |
| **61/61 (100%)** | `gan_ja` == `gan_fz` | 吉安贛語 == 撫州贛語 |
| 60/61 (98%) | `cjy_cz` == `cjy` | 長治晉語 == 太原晉語 |
| 59/61 (97%) | `cjy_lv` == `cjy` | 呂梁晉語 == 太原晉語 |
| 58/61 (95%) | `gan_ja` / `gan_fz` == `gan` | 吉安・撫州 == 南昌贛語 |

### なぜ「近縁だから似ている」では説明できないか

**根拠1 — 地図自身の基準線。** 実際に調査された下位方言行は、親から遠い:

```
wuu_sz 0%   hsn_sf 0%   cjy_xz 0%   hsn_ld 3%   gan_yc 5%
wuu_nb 18%  gan_yt 33%  cjy_dt 41%  yue_zs 52%  yue_gz 69%  czh_wy 69%
```

**70%〜95% に1行も存在しない。** 分布が二峰性で、上の6行だけが別集団にいる。

**根拠2 — WordMap という独立の証人。** 同じコードが WordMap にもあり、そちらは別途調査済み:

| コード | Han Map の一致 | WordMap の一致 |
|---|---|---|
| `hsn_hy` vs `hsn` | 61/61 (100%) | **4/41 (10%)** |
| `gan_ja` vs `gan_fz` | 61/61 (100%) | **10/42 (24%)** |
| `gan_fz` vs `gan` | 58/61 (95%) | **13/43 (30%)** |

**根拠3 — 声調型インベントリ。** これが決定的だった。`hsn_hy` の場合:

| | 使われている調値 |
|---|---|
| Han Map `hsn_hy` | ˦˩(17) ˨˦(15) ˩˧(11) ˧˧(9) ˨˩(5) ˦˥(4) ← **長沙と1つ違わず同一** |
| WordMap `hsn_hy` | **˥˩(26)** ˨˩(11) ˩˧(8) ˧˧(6) ˨˦(3) |

WordMap の衡陽行を支配する **˥˩ が、Han Map の衡陽行には1度も現れない**。
代わりに長沙の ˦˩ が全体を占める。`cjy_lv`（WordMap に ˨˩˧・˧˩˨・˥˦）、
`gan_fz`（˧˥・˧˨・˧）、`gan_ja`（˥˧・˧˩）も同様に、
**リポジトリ内の実調査データにしかない調値**を Han Map 行が欠いている。

### review 390 が見逃していた

review 390 は Sinologist 視点で 楊時逢《湖南方言調查報告》(hsn/hsn_hy/hsn_yz)、
侯精一《現代晉語的研究》(cjy/cjy_lv/cjy_xz) を参照したと記録している。
しかし**行同士が同一であることは、セルを1つずつ見る読み方では見えない**。
兄弟行の `hsn_yz`・`cjy_xz` は実際に差別化されており、
差別化されなかった6行だけが素通りしていた。

## 修正 — データは直さない。捏造になるから

366セルを埋めるには 衡陽・長治・呂梁・桂林平話・撫州/臨川・吉安 の字表が要る。
手元にない。**声調型は WordMap から分かっても、調類→調値の対応と分節音は分からない。**
推測で埋めれば長沙の読みを衡陽と偽るのと同じことをもう一度やることになるので、埋めない。

## 新設ガード — `tools/hanmap_dup_row_check.js`

全ペアの一致率を取り、90%（二峰性の谷）以上を報告する。2つのリストを持つ:

- **ALLOW（6ペア）** — 一致が言語事実として正しいもの。各々に理由を明記:
  `yue`/`yue_hk`/`yue_mo`（香港・マカオ・標準広東語は字音の規範が一つ）、
  `czh`/`czh_jx`（績溪が徽語の代表点＝親行そのもの）、
  `zh_cd`/`zh_sc`（成都が四川話の代表点）、
  `zh_th`/`zh_tw`（バンコク華人の官話は台湾の読み規範で教えられる）
- **DEBT（6行）** — 上記のコピー行。**violation ではなく debt として出す**ので
  ツリーは緑のまま、負債は毎回見える。行がリストを出れば、それが修理の完了。

**7つ目のコピーが現れれば violation。** DEBT の行が差別化されて一致しなくなれば
「リストから外せ」と出るので、リストが腐らない。

検証: `yue|yue_hk` と `hsn_hy` を一時的にリストから外す → `violations: 2` で両方検出。
戻す → `violations: 0, debt: 6`。

`check_all` は **39 → 40** ガード、全て緑。

## 波及 — review 452 がこのコピー行を出典に使っていた

review 452 は「52 tonal cells given back the tone, **from our own Han Map**」で、
Han Map の同一言語・同一字から声調を WordMap へ移した。移した52セルのうち **4セルが
今回の debt 行を出典にしていた**:

| セル | 452 が入れた値 | 出典の Han Map 行 |
|---|---|---|
| `cjy_lv` 鸟 | ˥˧ | `cjy_lv` = 太原のコピー |
| `cjy_lv` 五 | ˥˧ | 同上 |
| `gan_ja` 五 | ˨˩˧ | `gan_ja` = 南昌のコピー |
| `gan_fz` 五 | ˨˩˧ | `gan_fz` = 南昌のコピー |

452 は「**全清上と次濁上は上聲が分裂する方言では別調類なので、別の読みから
声調を取るのは誤り**」というフィルタを持ち、37セルを実際に弾いていた。
だがそのフィルタは分節音の一致で判定するので、**Han Map 側が親方言のコピーなら
分節音も親のものと一致してしまい、素通りする**。

### 各行自身の調類パターンで判定した

| 行 | 次濁上（耳・雨・我） | 全清上（水・狗） | 452 が入れた 五（次濁上） |
|---|---|---|---|
| `gan_fz` | 耳 ˧˥・雨 ˧˥（眼 ˧˥） | 水 ˧˨ | **˨˩˧ ← 行内のどれとも合わない** |
| `gan_ja` | 耳 ˥˧・雨 ˥˧（我 ˧˩） | 水 ˨˩˧・狗 ˨˩˧ | **˨˩˧ ← 全清上の値。五は次濁上** |
| `cjy_lv` | 耳 ˧˩˨・我 ˥˧ | 水 ˥˧・狗 ˥˧ | ˥˧（行内で割れており判定不能） |

`gan_fz`・`gan_ja` の 五 ˨˩˧ は南昌の上聲値で、**行自身の 上聲 反映と食い違う**。
ハンドオフ項目7 が `gan_fz` の 我 ˨˩˧ を「南昌の上聲値の混入」として独立に問題視しており、
五 はそれと同じ調類・同じ値。→ **声調を外して無調に戻した。**

無調セルは「出典が無い」という正直な穴で、声調完全性の検出器が再び報告する。
誤った声調は黙って嘘をつく。後者より前者を選ぶ。

`cjy_lv` の2セルは残した。˥˧ は出典のある呂梁行に12回現れる実在の調値で、
鸟（全清上）は行内の 水・狗 ˥˧ と整合する。五 は行内が割れているため判定できず、
根拠なく消せば別の誤りになる。ハンドオフに未検証として記録した。

## 同じ切り口を WordMap にも当てた — こちらは白

review 450 の汚染掃討は「**無関係な**2行が3概念以上一致」という切り口だったので、
`gan` と `gan_fz` のような**近縁ペアは原理的に引っかからない**。
そこで Han Map と同じ総当たり（1161言語）を WordMap にも当てた。

最初 88ペアが90%以上で出たが、うち断片古代語の塊
（`ncs` `txr` `xli` `cms` `xmr` `xve` `xib` `h_goguryeo` `p_jpk` が互いに88〜100%）は
**全セルが `—`** だった。`—` は「出典が無いので埋めない」というこのプロジェクトの正しい印であり、
2行が「未詳である」点で一致するのは汚染ではない。私の probe が `—` を実データとして
数えていただけだった（`ja` の件と同じ種類の自作自演）。

`—` を除いて95%以上に絞ると **25ペア、すべてフランス語・スペイン語の国別変種**
（`fr_be`==`fr_ch`、`es_co`==`es_pe` など）。基礎語彙が国境で変わらないのは正しいデータ。

**WordMap に新たな汚染は無い。** review 450 の結論は、近縁ペアの切り口でも成立した。
ただし `gan_fz` の WordMap 行が南昌と 13/43 一致しているのは既知（ハンドオフ項目7）で、
これは行全体のコピーではなく**混成**なので別問題として残る。

なお Han Map 側の空欄マーカーは `zkt`(43) `juc`(3) `pmgl`(2) のみで、
今回の6ペアには1つも無い。発見は空欄で膨らんでいない。
ガードにも同じ除外を入れた。
