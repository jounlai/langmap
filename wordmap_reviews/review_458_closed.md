# Review 458 — 地図間の整合（全体ラリー4／10）

**日付:** 2026-08-27
**切り口:** 同じコードが複数の地図に載っている。455 では WordMap を証人にして
Han Map のコピー行を暴いた。今度は逆に、**証人同士が食い違っていないか**を見る。

| 地図 | コード数 |
|---|---|
| Word Map | 1164 |
| Lang Map (`LANGUAGES` roster) | 242 |

**2つ以上の地図に載るコード: 292。**

## 座標 — 食い違い5件、すべて設計どおり

| コード | 差 | 内訳 |
|---|---|---|
| `en` | 99° | NameMap(39.5,-98.4)=アメリカ vs WordMap(51.5,-0.1)=ロンドン |
| `br` | 75° | NameMap=ブラジル vs WordMap=**ブルターニュ** |
| `ar` `zh` `id` | 12〜17° | 国重心 vs 首都／言語中心 |

NameMap は `NM_LANGS` の設計上「1国1セル」で、`en`=アメリカ・`gb`=イギリス、
`ar`=エジプト・`ars`=サウジ と明示的に分けている。だから食い違いではない。

`br` だけは性質が違う。**Word Map の `br` はブルトン語（ISO 639-1）、
NameMap の `br` はブラジル**で、同じ文字列が別の意味を持つ。
NameMap は `NM_LANGS` に自前の名前を持ち `LANG_NAMES` を引かないので現状は無害だが、
今後 NameMap を共有の名前テーブルに繋ぐときに必ず刺さる。ハンドオフに記録。

## 名前 — 242件の「不一致」はすべて不活性

Lang Map の roster は `name:'日本語(大阪弁)'` のように**日本語**で名前を持ち、
Word Map は `name:'Japanese (Osaka)'` と英語で持つ。242コードで食い違う。

しかし `app.js` の表示経路を全部たどると、言語名は**8箇所すべて `langName(code)`**
＝ `LANG_NAMES[読者のUI言語]` を通っており、`LANGUAGES[i].name` は
**どこからも描画されていない**。roster の name フィールドは死んでいる。
読者への影響はゼロなので、触らない（消すのは別の判断）。

## 発見 — IPA に上付き数字で声調を書いた行が2つ

音素記号の集合を地図間で比べる切り口は、61字と約50語では出る音が違うので
ノイズだらけだったが、1つだけ本物が混じっていた:

```
cjy_xz  word-only: ⁵³² r ¹ ⁴
```

家内規約は **IPA の声調は Chao 記号（˥˦˧˨˩）だけ**で、数字はローマ字表記＝surface 側の道具。
全域を数えると **Word Map に40セル、Han Map に0**。しかも2行に完全に集中していた。

| 行 | 数字表記のセル | 同じ行が Chao で書いているセル |
|---|---|---|
| `cjy_xz` 忻州晋語 | 20 | `bird niau˥˧` `blood ɕyəʔ˨˩` `ear ər˧˩˧` `five u˥˧` |
| `atb` 載瓦語 | 20 | `fish ŋa˥` `red ne˥˩` `three sum˥˥` `star kjoi˥` |

**別の規約を採っているのではなく、行が自分自身と食い違っている。**
`cjy_xz` は `bird niau˥˧` と `cat miau⁵³` を同時に持つ — 同じ声調、2つの書き方。

数字→Chao は1対1（1→˩ 2→˨ 3→˧ 4→˦ 5→˥）で言語判断を含まないので、40セル変換した。

### 1件だけ表記変換で済まなかった

`cjy_xz` sun `太阳` は **`tʰai⁴⁵ iɒ̃¹¹˥`** — 1音節の中に数字と Chao が同居し、
そのまま変換すると `˩˩˥` という、この行が他で一度も使わない三段の輪郭になる。

調類から決めた。**陽 は 以母平聲 ＝ 陽平** で、これは 魚（疑母平聲）と同じ調類。
この行は 魚 を `y˩˩` と書いている。**同一調類は同一調値**というこのプロジェクトの原則から
`iɒ̃˩˩`、末尾の `˥` は変換のやり残しと判断した。→ `tʰai˦˥ iɒ̃˩˩`

## 直さなかったもの — `atb` の surface

`atb` は36セル中**20が `tsa51` 式の数字ローマ字**、16が Zaiwa 正書法（`kyoq` `nga` `sui`）。
surface も行内で2系統に割れている。だが正しい Zaiwa 綴りは語ごとに出典が要るので触らない。
IPA と違い、こちらは表記変換では済まない。ハンドオフに記録。

## 新設ガード — `tools/ipa_digit_check.js`

IPA フィールドに数字（半角・上付きとも）があれば violation。
**Word Map・Han Map（本読み＋異読）・NameMap の4データセット全部**を読む
（Lang Map に IPA フィールドは無い）。どの声調かは問わない、数字で書くなという表記だけの検査。

検証: `atb one` を `ʒa21` に戻す → `[WordMap] one/atb /ʒa21/` を検出。戻して0。

`check_all` は **40 → 41** ガード、全て緑。
