# Review 570 — round 92: lexibank-analysed leads

Closed 2026-10-12. Five agents. Working files: ~/langmap-work/r92/,
~/langmap-work/lexa/ (match.js joins lexibank-analysed forms to empty atlas
cells through Glottolog glottocode → ISO; lexibank-analysed itself carries no
ISO codes, so without the Glottolog table only 16 rows match).

535 candidate cells on 171 rows → 48 accepted (~9%). Why leads failed:
1. the row writes a script or practical orthography the dataset does not
   (Burmese, Tibetan, Yi, Cyrillic, Ge'ez …) and no source prints the word
   in it — 19 of 23 Old Burmese leads;
2. the doculect is another variety (asu = Asuriní, Bernese for Alsatian,
   Koelle's Yekhee, Kartujarra for Martu Wangka, Demotic for Katharevousa);
3. old or second-hand lists without a modern second source (Koelle 1854,
   Johansson's sound-symbolism compilation);
4. already rejected in earlier rounds; wrong gloss (blue/green, girl).
Accepted: nmn 6, obr 4, nha 3+, mcf 2, adt 2, ii 2, ude 2, swi 2, wmt, orh,
atb, afb, dta, lic … Rulings: obr wind lij inherited from PST *qV-lij;
wmt lirra mouth = tooth (one word); locked mcf/mpj blue sharing, nxq
hundred = person ɕi˧.

Conclusion: the lexibank collection has largely been mined already by the
per-dataset rounds; the join is worth re-running only when lexibank adds
datasets.
