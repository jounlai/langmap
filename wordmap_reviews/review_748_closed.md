# Word Map review 748 — reader comment: pre-colonial Tagalog "thank you" (2026-11-17)

Reader (public comment): pre-colonial Tagalog would not say salamat (an Arabic word) but nanghaw, Baybayin ᜈᜑ.
Checked (Wiktionary, kaikki dump): nanghaw is real — noun 'thanks' and interjection 'thank goodness; fortunately',
both tagged obsolete, from panghaw 'attainment of a desire'. salamat is a loan through Malay selamat < Arabic
salāma; Malay-mediated Arabic words reached Tagalog before the Spanish, so "Arabic" does not make it post-colonial.
Decision: keep salamat (the everyday word; wordmap-major-word-only), add a cell note naming nanghaw. ᜈᜑ is how
na(ng)-ha(w) is written without final-consonant marks; the row writes final consonants with the virama
(43 of 82 cells), so the note spells it ᜈᜅ᜔ᜑᜏ᜔.
