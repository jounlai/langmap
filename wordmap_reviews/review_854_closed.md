# Review 854 — etymological routes for the six new words; 29 more cells; Acehnese paper

2026-11-27. Follows review 853 (owner 「はい、続けてください」).

## Routes
I used the basic-word method (BRIEF_BASE + applybase.js): one agent per word, and only etyma that a named source supports. Each route needs 4+ cells, and a cell goes in only when a descendants list or reflex list names it. The agents' assignments were then trimmed by me wherever a cell was placed only by zone, by likeness, or as "the same word as a relative" with no listing:
- see: Bantu -mona ×4; Austronesian *kita ×6.
- hear: Bantu *-jígu ×12 (zone-matched); wa, nog, kum, sms, jv.
- die: Bantu ×14; Austronesian ×5; Sino-Tibetan ×3; sel, krc, pcc, tly; the Mongolic *ükü- route, which fell under 4.
- knee: the Proto-Cushitic route (Amharic is only "of Cushitic origin").
- skin: Bantu *-kóbá (form within zones); Mongolic *arasun (unlisted); Latin cutis in *kéwHtis (only "cognate"); Muong in Vietic *taː.
- leaf: zza pelg (velg is listed); sga duille (duilne is listed).
