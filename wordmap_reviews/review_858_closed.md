# Review 858 — etymological routes for horn, breast, liver, come, road, full

2026-11-27. Follows review 857.

## Method
The same method as review 854:
- one agent per word, working from BRIEF_BASE and applybase.js;
- a cell joins a route only when a descendants list, reflex list or cognate set names that language (or a stage or dialect of it);
- never by zone, family or likeness alone.

## Trimmed by me
- **horn:**
  - rw (Kinyarwanda; only the Rundi form is listed)
  - the -phondo route (one expert cognate set and no reconstruction): zu, xh, nd, tum, ts
- **liver:**
  - pag altey (an ACD note only, irregular)
  - ps ينه (from the derived *yáxnyaH)
  - the *pečenь route: it reaches 4 cells only with Ukrainian печінка, a diminutive that is not on the list, so ru, be, uk and sk become plain
- **come:**
  - the āpayati route (hi, ur, ne, pa, pnb, gu, rmy, rom): IE-CoR files Hindi ānā under *gʷem-, so the sources disagree
  - Persian آمدن ×4 (Wiktionary *gʷem-, IE-CoR *h₁ey-)
  - the "Canaanite בוא" route (a "compare" note only): hbo, he, phn, xpu
- **road:**
  - lo, khb, shn from the 唐 route (they reach it only through Proto-Southwestern Tai); vi đường stays
  - ln nzelá (Wiktionary: a loan from Kongo)
  - rmy (not listed)
- **full:**
  - se, smj, smn from *täwde (an older view derives the Sami word from Germanic)
